## CARATOM mapping

- Swiggy folder tabs → **General service + repair** (first) · **General service** · **One-man job** · **SOS**
- Brand/model flows → vehicle picker (logos then photos)
- Service home → photo/ad masthead with location + vehicle on it, then Swiggy folder tabs, then tab body. Use the yellow-home composition, not its yellow brand.
- SOS → emergency / roadside entry in nav

## Color interpretation

CARATOM is not a blue-washed app. White and near-white surfaces dominate. Light blue is used selectively for primary actions, selected tabs, active navigation, links, and vehicle/selection emphasis. Green, amber, and red retain semantic roles. See `docs/architecture/10-design-system.md` for the canonical design system.
